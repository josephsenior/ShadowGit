# Changelog

All notable changes to ShadowGit will be documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Standalone Python API and command-line interface.
- Incremental, Git-object-backed snapshots.
- Conservative restore with quarantine.
- Symbolic-link and executable-mode preservation.
- Durable interrupted-restore journal and explicit recovery.
- Snapshot-history pruning with old-to-new SHA mapping.
- Snapshot inspection, diff, and integrity verification.
